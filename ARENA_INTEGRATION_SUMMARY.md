   - Checks QR session status

### Website Scanner
1. ✅ **Dynamic QR Detection**
   - Detects Arena login QR: `session=` parameter
   - Detects Event QR: Pre-generated by admin
   - Routes to appropriate handler

2. ✅ **Arena Login Handler**
   - Extracts session ID from QR
   - Calls `authenticate_qr_session` RPC function
   - Updates session status to 'authenticated'
   - Shows success message

## 🔄 Workflow

### Arena Login Flow:
1. **Desktop**: User opens Arena → Shows QR login screen
2. **Desktop**: Generates QR with session ID → Saves to database
3. **Desktop**: Starts polling for authentication
4. **Mobile**: User opens website → Scans QR code
5. **Website**: Detects Arena QR → Authenticates session
6. **Database**: Updates QR session status to 'authenticated'
7. **Desktop**: Polling detects authentication → Logs in user
8. **Desktop**: Shows games list

### Event QR Flow (Existing):
1. **Admin**: Pre-generates event QR codes
2. **Mobile**: User scans event QR
3. **Website**: Reduces game chances
4. **Database**: Records scan in `game_scans` table

## 🔑 Database Functions Used

### `authenticate_qr_session(p_session_id, p_user_id)`
- Updates QR session status to 'authenticated'
- Links session to user
- Updates user's last_login
- Returns boolean success

### `create_qr_session(p_session_id, p_desktop_device_id, p_expiration_minutes)`
- Creates new QR login session
- Sets expiration time
- Returns session UUID

### `get_active_game_session(p_user_id)`
- Retrieves user's active game session
- Returns games_remaining count
- Checks expiration

## 📊 Database Schema

### `qr_login_sessions`
- `id` (UUID)
- `session_id` (TEXT, unique)
- `user_id` (UUID, nullable)
- `status` (TEXT: pending/scanned/authenticated/expired)
- `created_at` (TIMESTAMP)
- `expires_at` (TIMESTAMP)
- `desktop_device_id` (TEXT)

### `users`
- `id` (UUID)
- `phone_number` (TEXT, unique)
- `username` (TEXT)
- `email` (TEXT)
- `created_at` (TIMESTAMP)
- `last_login` (TIMESTAMP)

### `game_sessions`
- `id` (UUID)
- `user_id` (UUID)
- `session_token` (TEXT, unique)
- `games_remaining` (INTEGER)
- `expires_at` (TIMESTAMP)
- `is_active` (BOOLEAN)
